# Толк · Поиск контекста — Discovery Prototype

Неофициальный UX-прототип гипотезы для Контур.Толка: **единый поиск по расшифровкам и протоколам встреч внутри одной «Темы» помогает быстрее находить конкретные решения и договорённости**.

## Запуск

Откройте `index.html` в браузере. Без сборки, ключей API и сервера.

## Что работает

- Локальный текстовый поиск по 6 вымышленным материалам встреч.
- Фильтры «Все источники», «Расшифровки», «Протоколы».
- Быстрые исследовательские задачи и обработка пустой выдачи.
- Открытие точного текста источника с датой, автором и таймкодом.
- Адаптивный интерфейс для десктопа и мобильного устройства.

**Ограничения:** поиск простой, лексический, не семантический и не на базе LLM; переход к настоящей записи не реализован; данные демонстрационные. Функции импорта, авторизации, интеграций и real-time обновления отсутствуют. Внедрение в реальный B2B-продукт потребует серверной проверки прав доступа, индексации, хранения и безопасной обработки персональных данных.

## Гипотеза

Когда пользователь возвращается к проекту и ищет договорённость, единый поиск с источником и таймкодом позволит чаще успешно завершать задачу и сократит время поиска относительно текущего сценария открытия отдельных записей и чатов.

## План тестирования

1. Пригласить 8–12 сотрудников SMB, которые регулярно возвращаются к старым встречам.
2. Для каждого участника сравнить существующий сценарий и прототип на равнозначных поисковых задачах (перемешать порядок).
3. Измерить: успешность задач, медианное время, число переходов, возможность подтвердить цитату и субъективное доверие.
4. Предварительные критерии: >=80% успешных задач, >=50% сокращения медианного времени и корректная привязка каждого найденного фрагмента к источнику.
5. После качественных тестов решить, достаточно ли обычного поиска или нужен AI Answer с цитированием.

## Публикация в GitHub Pages

1. Создайте новый публичный репозиторий, например `tolk-context-search`.
2. Загрузите файлы `index.html`, `app.js`, `data.js`, `README.md` в корень репозитория.
3. Перейдите `Settings → Pages → Build and deployment → Deploy from a branch`, выберите ветку `main`, папку `/ (root)` и сохраните.
4. Ссылка после публикации будет иметь вид `https://<username>.github.io/tolk-context-search/`.

## Источник гипотезы

Пользователь предоставил пример Product Nexus Контур.Толка: жалобы SMB на невозможность поиска решений по записям, расшифровкам, чатам и файлам. Реальных пользовательских данных в репозитории нет.
